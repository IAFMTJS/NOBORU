# 02 - Journey Trails And World Map

Source: `D:/NOBORU ART/Mockup (2).PNG`

The journey screens are the heart of Noboru. They show language lessons as a magical mountain trail. Every trail concept must show progress spatially, not just as a progress bar. The path is a winding visual metaphor for learning.

## Core Trail Anatomy

- Vertical phone screen with rounded corners.
- Full-bleed painted background: mountain village, forest, temple peak, summit, event route, or boss shrine.
- Winding path of stones or glowing dots travels from lower screen to upper screen.
- Lesson nodes sit directly on the path.
- Current lesson is larger and brighter.
- Completed nodes are brighter, warmer, or checked.
- Locked nodes ahead are grey, fogged, or have lock icons.
- Background contains lanterns, trees, rooftops, cliffs, mountains, torii gates, clouds, and mist.
- Bottom navigation is present on most journey screens.
- Top overlay often shows player profile, streak, currency, or region progress.

## Path Visual Language

### Standard Path

- The path is made of uneven circular stones or stepping lights.
- The stones are warm cream/amber against dark blue forest.
- Some stones are connected by a faint glowing thread.
- Larger lesson nodes use circular rings with icons.
- The path narrows in the distance, adding depth.
- Lanterns often punctuate the path, echoing the node glow.

### Completed Path

- Completed sections glow brighter and more continuous.
- Previous nodes have warm filled centers.
- A green check can mark region completion or a finished lesson.
- Background behind completed path may become slightly warmer and clearer.

### Future Path

- Future path remains visible but dim.
- Fog overlays reduce contrast.
- Lock icons replace normal lesson symbols.
- Cards state why the next region/lesson is locked.
- Use blue-grey desaturation, not total invisibility.

### Event Path

- Sakura petals sit along the route.
- The path line or node accents shift to red/pink.
- Blossoms can cluster around locked and active event nodes.
- Event progress card floats near top-left.

### Boss Path

- Red-orange glow, smoke, volcanic temple silhouette.
- Boss node uses a large red circular seal with mask/oni/fox face.
- Background architecture looms larger and more threatening.
- Ordinary path nodes are subdued under red lighting.

## Node Icon Library

- Camp/lesson node: triangular mountain tent.
- Vocabulary/kanji node: stylized kanji/tree mark.
- Listening node: headphones.
- Locked node: padlock.
- Boss node: red mask/oni face.
- Completed node: green check.
- Region node: mountain, forest/tree, torii, summit icon.
- Event node: sakura blossom.

## Bottom Navigation In Journey Screens

Most journey screens use:

- `Journey` active in orange/gold.
- `Camp`, `Study`, `Bag`, `Profile` inactive grey.
- Small icon above label.
- Background is dark transparent bar at the bottom.
- Icons are simple outline/filled hybrid, readable at tiny size.

## Trail Generation Acceptance Criteria

- The path must be navigable by eye from bottom toward top.
- Current state, locked state, and completed state must be distinguishable without reading text.
- Background should not be random fantasy art; it must include trail, lanterns, Japanese shrine/temple motifs, and mountain depth.
- At least one small environmental light source should be visible in every trail screen.
- UI cards must use Noboru dark glass/parchment material, not default app rectangles.
