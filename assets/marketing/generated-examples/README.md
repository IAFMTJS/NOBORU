# Generated art examples (reference only)

AI-generated illustration batches created as **style examples**, not production building blocks.

These are full compositions, mockup-style panels, and illustrated squares — **not** the composable assets the app needs (transparent character stickers, 9-slice UI materials, small bold icons, environment plates with UI-safe zones).

## Rules

- **Never** publish or serve from `public/art/`
- **Never** ingest into `assets/art/_source/` without export-rule review
- Use only as visual reference alongside `assets/marketing/mockup_*.png`
- Real production art goes in `assets/art/_source/` per [art-direction/06](../../art-direction/06_asset_inventory_and_naming.md)

## Layout

Mirrors art-direction category paths (`backgrounds/`, `characters/`, `ui/`, etc.) for easy comparison with the asset inventory checklist.

`_staging/` holds flat filenames from batch ingest attempts.
