NOBORU TRAINING GROUNDS SYSTEM

Purpose

The Journey Map teaches.

The Training Grounds create mastery.

These are two separate but connected systems.

Most language-learning apps only focus on progression.

Players move forward regardless of whether knowledge is truly mastered.

Noboru should separate:

Learning

from

Training

The Journey introduces knowledge.

The Training Grounds reinforce knowledge.

Together they create long-term retention.

⸻

Core Philosophy

The Journey answers:

“What should I learn next?”

The Training Grounds answer:

“What should I practice right now?”

The Journey creates motivation.

The Training Grounds create mastery.

Both systems are equally important.

⸻

Problem With Traditional Learning Paths

Most learning apps force players through lessons.

Players often think:

“I completed the lesson.”

But completion does not equal mastery.

Many users continue progressing while forgetting previous content.

This creates knowledge gaps.

⸻

Solution

Introduce a dedicated Training Grounds system.

A separate environment focused entirely on deliberate practice.

The player enters voluntarily to improve weak areas.

No story progression.

No region progression.

No mandatory lessons.

Only training.

⸻

Integration With Noboru World

Training Grounds should not feel disconnected.

They should exist inside the world itself.

Examples:

🏯 Kana Dojo

📜 Reading Library

🏹 Vocabulary Hall

⛩ Grammar Shrine

🎧 Listening Pavilion

⚔️ Mastery Arena

The player discovers these locations during their journey.

Opening them launches specialized training systems.

This makes practice feel like part of the world.

Not a separate utility screen.

⸻

Access Methods

Players can access Training Grounds from:

1. Dedicated Training Tab

OR

2. Physical locations on the world map

Ideally both methods exist.

⸻

Kana Dojo

Purpose:

Master Hiragana and Katakana.

Training modes:

* Learn
* Practice
* Writing
* Recognition
* Speed Challenge
* Mastery Test

⸻

Kana Learn Mode

Introduces new characters.

Shows:

* Character
* Pronunciation
* Stroke order
* Examples

Focus is understanding.

Not speed.

⸻

Kana Recognition Mode

Shows a character.

Player selects the correct answer.

Example:

あ

Choices:

a
i
u
e

⸻

Kana Writing Mode

Displays a character.

Player writes it manually.

The system evaluates:

* Stroke shape
* Accuracy
* Recognition

Feedback is immediate.

⸻

Kana Speed Challenge

Rapid recognition challenge.

Character appears briefly.

Player must answer before time expires.

Focus:

Automatic recognition.

Not conscious memorization.

⸻

Kana Mastery Test

Exam covering all learned characters.

Rewards mastery status.

Used to identify weaknesses.

⸻

* Flashcards

⸻

⸻

Weakness Training System

This is one of the most important systems.

The platform tracks every answer.

Every item receives a mastery score.

Example:

あ = 97%

い = 94%

ぬ = 41%

め = 33%

The player can launch:

Train Weak Items

The system automatically creates exercises using weak content.

This creates highly efficient learning.

⸻

Smart Review System

The platform continuously tracks:

* Correct answers
* Incorrect answers
* Time to answer
* Confidence level
* Review history

Weak items appear more frequently.

Strong items appear less frequently.

Inspired by spaced repetition systems.

⸻

Daily Training Recommendations

Every day Noboru recommends:

Today’s Focus

Example:

* 5 weak Hiragana
* 8 weak vocabulary words
* 2 grammar concepts

This provides clear direction.

⸻

Not lesson completion.
