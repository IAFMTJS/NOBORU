NOBORU EDUCATIONAL GAME SYSTEM

Version: 1.0

Status: AUTHORITATIVE

This document defines all game systems inside Noboru.

Every game, challenge, activity, event, trial, boss encounter, and future game mode must follow this document.

No game may be created outside this framework.

This document exists to ensure games improve learning instead of distracting from it.

⸻

GAME PHILOSOPHY

Games exist to strengthen learning.

Games do not exist to increase screen time.

Games do not exist to maximize engagement.

Games do not exist to manipulate users.

⸻

PRIMARY RULE

A game must teach.

If a game is fun but teaches nothing:

It fails.

If a game teaches but is painful:

It fails.

Games must balance:

Learning

Fun

Retention

Challenge

Progress

⸻

GAME OBJECTIVES

Games should:

Improve recall

Improve recognition

Improve retention

Improve confidence

Increase repetition

Reduce boredom

Strengthen mastery

⸻

FORBIDDEN GAME DESIGN

Grinding

Pay-to-win

Energy systems

Artificial waiting

Reward addiction loops

Gacha mechanics

Loot boxes

Manipulative retention systems

Fear-of-loss mechanics

⸻

GAME CATEGORIES

Learning Games

Review Games

Boss Trials

Region Challenges

Seasonal Games

Mastery Games

⸻

GAME REWARD RULE

Rewards accelerate motivation.

Rewards do NOT replace learning.

Learning progression remains educationally earned.

⸻

EDUCATIONAL PRIORITY

Order of importance:

1. Educational Value
2. Retention Improvement
3. User Enjoyment
4. Replayability
5. Rewards
