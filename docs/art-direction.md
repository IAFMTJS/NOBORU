# Art direction

Authoritative art direction lives in **[`art-direction/`](../art-direction/README.md)** at the repo root.

That folder documents the four canonical mockup boards and defines palette, materials, screen rules, Cursor generation briefs, and asset naming — for producing **new illustrated art**, not ingesting mockup panels as backgrounds.
