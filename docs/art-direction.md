NOBORU ART DIRECTION SYSTEM

Version: 1.0

Status: AUTHORITATIVE

This document governs all visual identity, illustrations, mascots, icons, achievements, regions, enemies, assets, promotional material, and future generated artwork within Noboru.

No visual asset may be created without following this document.

This file is the single source of truth for Noboru’s visual universe.

⸻

CORE PHILOSOPHY

Noboru is not a language app.

Noboru is a journey of ascent.

Every visual element must reinforce:

Progress

Exploration

Discovery

Achievement

Mastery

Wonder

⸻

VISUAL GOAL

Users should immediately recognize Noboru.

Even without seeing the logo.

Every illustration should feel like it belongs to the same world.

Every icon should feel related.

Every badge should feel connected.

Every screen should feel part of the same adventure.

ART SUCCESS CRITERIA

If an asset is shown without context:

Users should still recognize:

“This belongs to Noboru.”

⸻

ART FAILURE CRITERIA

If an asset could belong equally to:

A crypto project

A random anime app

A corporate SaaS

A mobile gacha game

Then the asset fails review.
