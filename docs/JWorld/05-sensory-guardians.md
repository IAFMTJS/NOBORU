# Sensory progression, guardians & lateral mechanics

## Sensory progression per world

| World | Time of day | Weather | Dominant sound |
|-------|-------------|---------|----------------|
| N5 | Dawn → morning | Soft mist | Village bells, distant stream |
| N4 | Morning → noon | Light rain optional | Bamboo creak, waterfalls |
| N3 | Afternoon | Rolling fog | Wind, distant thunder |
| N2 | Dusk | High wind | Chimes, flag flutter |
| N1 | Night → starlight | Clear cold air | Silence, single shrine bell |

**Theme rule:** Dark mode is canonical (master spec). Light mode = morning exploration variant per world.
