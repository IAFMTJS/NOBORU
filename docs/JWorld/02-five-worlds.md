Session 1 draft. Names and layers are proposals for reaction.

## N5 — Realm of First Light

**Japanese working title:** 始まりの境 (*Hajimari no Sakai*)

| Aspect | Detail |
|--------|--------|
| **Pedagogical soul** | First words, survival Japanese, hiragana/katakana, basic grammar, ~100 kanji |
| **Emotional arc** | Wonder, safety — “I can do this.” |
| **Visual identity** | Warm lantern glow, village roofs, misty valley floor, torii at dawn |
| **Avoid** | Underground roots / cave network (too tree-coded) |

**Deep-dive (Session 2):** [06-n5-deep-dive.md](./06-n5-deep-dive.md) — landmarks, acts, portal script, art brief.

### Three acts (summary)

| Act | Trail zones |
|-----|-------------|
| I — Awakening | Ember Threshold → Script Sanctum → Kana Bridge |
| II — First steps | Lantern Hamlet → Market Bend |
| III — The climb begins | Forest Torii → Kanji Grove → Gate of Ascent |

One N5 world — see [08-target-structure.md](./08-target-structure.md).

### Layers

| Layer | Place | Learning vibe |
|-------|-------|----------------|
| Deep | **Script Sanctum** | Hiragana/katakana as glowing stone tablets |
| Low | **Lantern Hamlet** | Greetings, numbers, daily life |
| Mid | **Forest Crossing** | Vocabulary trails, first kanji |
| High | **First Slope Shrine** | Grammar patterns, listening |
| Peak | **Gate of Ascent** | N5 Trial → portal to N4 |

| Token | Use |
|-------|-----|
| **Palette** | Lantern gold, moss green, soft spirit blue |
| **Guardian** | **Guardian of First Light** (see deep-dive) |
| **Yama** | Curious, playful; discovers hidden paths with you |

**Note:** N5 is the longest scroll; origin story. Lesson content from the old split is merged under world `n5` at implementation — [legacy-slugs.md](./legacy-slugs.md).

## N4 — Realm of the Green Ascent

**Japanese working title:** 翠の登り (*Midori no Nobori*)

| Aspect | Detail |
|--------|--------|
| **Pedagogical soul** | Daily conversation, past tense, more kanji, longer sentences |
| **Emotional arc** | Confidence, routine — “Japanese is becoming familiar.” |
| **Visual identity** | Bamboo valleys, waterfall bridges, moss shrines, wider trails |
| **Avoid** | Generic “foothills” label — you’re already climbing; first **serious** mountain |

### Layers

| Layer | Place | Learning vibe |
|-------|-------|----------------|
| Entry | **Mist Bridge** | Transition from N5 — weather shifts |
| Mid | **Bamboo Pass** | Expanded vocab, particle depth |
| High | **Shrine of Patterns** | Grammar consolidation |
| Peak | **Wind Torii** | N4 Trial |

| Token | Use |
|-------|-----|
| **Palette** | Deeper greens, amber accents, more sky visible |
| **Guardian** | *Kaze no Mori no Nushi* — forest keeper |
| **Yama** | Encouraging; points out world patterns that mirror grammar |

## N3 — Realm of the Cloudline

**Japanese working title:** 雲境 (*Kumokyo*)

| Aspect | Detail |
|--------|--------|
| **Pedagogical soul** | Independent comprehension, nuance, keigo introduction, reading stamina |
| **Emotional arc** | “The mountain is real now.” Effort, fog, persistence. |
| **Visual identity** | Stone ridges, cloud sea below, exposed paths, distant peaks |
| **Avoid** | Tree trunk rings — use **cloud terraces** or **ridge switchbacks** |

### Layers

| Layer | Place | Learning vibe |
|-------|-------|----------------|
| Entry | **Cloudbreak Stair** | Step out of forest into open air |
| Ring 1 | **Ridge of Recognition** | Reading, listening at length |
| Ring 2 | **Mist Library** | Kanji density, compound words |
| Ring 3 | **Keigo Pavilion** | Politeness, social context |
| Peak | **Storm Lantern** | N3 Trial |

| Token | Use |
|-------|-----|
| **Palette** | Sage grey-green, spirit blue mist, cooler tones |
| **Guardian** | *Kumogiri no Kenja* — warden of clarity through fog |
| **Yama** | More guide than playmate; sits with you at overlooks |

## N2 — Realm of the Sky Temple

**Japanese working title:** 空殿 (*Kūden*)

| Aspect | Detail |
|--------|--------|
| **Pedagogical soul** | Work/study Japanese, newspapers, abstract topics, speed |
| **Emotional arc** | Discipline, altitude, respect for the height |
| **Visual identity** | Pagodas above clouds, wind chimes, narrow sky bridges, celestial carp streams |
| **Avoid** | “Canopy” as tree — think **floating temple tier** |

### Layers

| Layer | Place | Learning vibe |
|-------|-------|----------------|
| Entry | **Veil of Clouds** | Dramatic transition — world opens up |
| Mid | **Scriptorium of Currents** | Reading news-style passages |
| High | **Bridge of Nuance** | Grammar edge cases, formal register |
| Peak | **Thunder Gate** | N2 Trial |

| Token | Use |
|-------|-----|
| **Palette** | Moonlit sage, spirit blue, fox orange as warmth against cold sky |
| **Guardian** | *Raijin no Shisha* — tests readiness, not evil |
| **Yama** | Quiet companion; reacts to wind, watches shrines |

## N1 — Realm of the Celestial Summit

**Japanese working title:** 天頂 (*Tenchō*)

| Aspect | Detail |
|--------|--------|
| **Pedagogical soul** | Near-native fluency, literary Japanese, mastery |
| **Emotional arc** | Awe, humility, completion — not “you won,” but “you arrived.” |
| **Visual identity** | Star fields, sacred peak, ancient observatory, aurora-like spirit light |

### Layers

| Layer | Place | Learning vibe |
|-------|-------|----------------|
| Entry | **Starfall Gate** | From N2 sky into rarefied air |
| Mid | **Hall of Echoes** | Literary texts, classical allusions |
| High | **Crown Observatory** | Production, synthesis |
| Peak | **Summit of Noboru** | N1 Trial + mastery recognition |

| Token | Use |
|-------|-----|
| **Palette** | Deep indigo, lantern gold as starlight, restrained purple (not neon) |
| **Guardian** | *Tenchō no Shō* — master, not boss monster |
| **Yama** | Full companion arc payoff — shared summit moment |
