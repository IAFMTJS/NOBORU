NOBORU UI SPECIFICATION

DOCUMENT 05

COMPANION SYSTEM

Version 1.0

⸻

PURPOSE

The Fox Companion is the emotional anchor of Noboru.

The fox exists to create attachment.

The fox exists to create encouragement.

The fox exists to make progress feel personal.

The fox is not a decoration.

The fox is not a mascot.

The fox is a companion.

Every interaction with the fox should strengthen the player’s connection to the world.

⸻

CORE PHILOSOPHY

The fox is travelling alongside the player.

The fox is not employed by the application.

The fox is not an instructor.

The fox is not a tutorial character.

The fox is a fellow traveler.

The player and fox are climbing the mountain together.

⸻

PERSONALITY

The fox is:

curious

loyal

encouraging

playful

determined

kind

observant

⸻

NEVER

The fox is never:

sarcastic

aggressive

annoying

hyperactive

childish

mean

passive aggressive

judgmental

⸻

EMOTIONAL ROLE

The fox celebrates success.

The fox acknowledges effort.

The fox encourages consistency.

The fox never shames failure.

The fox never punishes mistakes.

The fox always feels supportive.

⸻

VISUAL PLACEMENT RULES

The fox should feel physically present.

The fox must appear integrated into the environment.

The fox should never appear floating.

The fox should never overlap critical interface elements.

The fox should never obstruct content.

JOURNEY SCREEN BEHAVIOR

The fox accompanies progression.

The fox remains near the player’s current lesson position.

The fox visually communicates direction.

The fox should naturally face the next objective.

⸻

JOURNEY POSITIONING

The fox should remain near the trail.

The fox should not sit directly on lesson nodes.

The fox should not cover interactive elements.

The fox should feel like it is travelling alongside the player.

⸻

CAMP SCREEN BEHAVIOR

The fox becomes most expressive in camp.

The camp is where personality is shown.

The fox should perform ambient actions.

The fox should feel comfortable here.

⸻

IDLE VARIATION

The same animation should not repeat constantly.

Animation variety should create life.

The fox should appear unpredictable in small ways.

FOX EVOLUTION

The fox should feel increasingly connected to the player.

The fox does not evolve physically.

The relationship evolves.

The player should feel:

we’ve been on this journey together

⸻

ADVANCED PLAYER EXPERIENCE

Long-term players should recognize behaviors that new players have never seen.

Rare animations may unlock.

Rare reactions may unlock.

Special interactions may unlock.

These should feel earned.

⸻

COMPANION MEMORY

The fox should appear aware of player achievements.

The fox should celebrate major milestones.

The fox should acknowledge long streaks.

The fox should react to important accomplishments.

⸻

IMMERSION RULES

The fox always exists within the world.

The fox never feels like a UI element.

The fox never appears as a floating assistant.

The fox is a character.

Not a feature.

⸻

FORBIDDEN DESIGNS

Do not use:

chatbot behavior

constant speech bubbles

forced interactions

tutorial spam

nagging reminders

aggressive retention mechanics

notification abuse

The fox should create affection.

Not dependency.
