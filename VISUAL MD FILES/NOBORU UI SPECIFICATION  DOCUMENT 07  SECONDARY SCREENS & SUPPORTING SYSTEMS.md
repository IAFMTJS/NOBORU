NOBORU UI SPECIFICATION

DOCUMENT 07

SECONDARY SCREENS & SUPPORTING SYSTEMS

Version 1.0

⸻

PURPOSE

This document defines all supporting screens outside the core Journey, Study and Camp experiences.

These screens provide functionality.

However, they must never break immersion.

The player should always feel connected to the world.

Secondary screens are supporting experiences.

They are not the primary experience.

⸻

CORE PRINCIPLE

No screen should feel disconnected from Noboru.

No screen should feel like a settings menu pasted from another application.

No screen should feel corporate.

No screen should feel technical.

Every screen remains part of the world.

Not abandoned.

EMPTY STATE PHILOSOPHY

You have not discovered this yet.

You have nothing.

⸻

TABLET RULES

Secondary screens must scale gracefully.

Layouts should expand.

Not stretch.

⸻

LARGE SCREEN RULES

Use additional spacing.

Use additional artwork.

Do not simply enlarge UI.

⸻

IMMERSION RULES

Every secondary screen remains connected to the world.

No screen should feel imported from another application.

No screen should feel generic.

No screen should feel temporary.

Every screen belongs to Noboru.

⸻

FORBIDDEN DESIGNS

Do not use:

corporate dashboards

analytics-heavy layouts

fintech-style cards

administrative interfaces

generic settings menus

app-store style shops

spreadsheet inventories

achievement grids with no personality

The player should always feel like a traveler within a living world.

Not a user managing an account.
