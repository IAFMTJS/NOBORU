NOBORU UI SPECIFICATION

DOCUMENT 04

CAMP & HOMEBASE SYSTEM

Version 1.0

⸻

PURPOSE

The Camp is the emotional center of Noboru.

The Journey is where progress happens.

The Camp is where progress is celebrated.

The Journey creates ambition.

The Camp creates attachment.

The Camp should feel like returning home after a day of travel.

Every design decision must reinforce this feeling.

⸻

CORE PHILOSOPHY

The Camp is not a dashboard.

The Camp is not a statistics page.

The Camp is not a menu.

The Camp is a physical location inside the world.

The player should feel present in this place.

The player should recognize it instantly.

The Camp should become emotionally familiar over time.

⸻

CAMP ROLE

The Camp serves six purposes.

1. Home Base
2. Daily Activities
3. Quest Management
4. Companion Interaction
5. Progress Reflection
6. Reward Collection

The Camp should never feel overwhelming.

The player should immediately understand where everything is located.

⸻

ENVIRONMENT

The Camp uses existing approved artwork.

Never generate replacement camp environments.

Never procedurally create camp structures.

Only approved camp assets may be used.

⸻

VISUAL ATMOSPHERE

Time of Day:

Early Evening

Lighting:

Warm

Golden

Comfortable

Safe

⸻

EMOTIONAL GOAL

The player should feel:

comfortable

welcomed

rewarded

motivated

curious

The player should never feel:

pressured

overwhelmed

lost

confused

⸻

CAMP LAYOUT

The Camp is a single scene.

Not a collection of cards.

Not a dashboard grid.

Not a menu screen.

The scene contains interactive locations.

⸻

CAMP CENTERPIECE

The campfire is the visual center of the Camp.

Everything is organized around it.

The fire symbolizes progress.

The fire symbolizes persistence.

The fire is visible at all times.

⸻

CAMPFIRE RULES

The fire is always lit.

The fire never disappears.

The fire continuously animates.

The fire emits:

light

embers

warm glow

subtle particle effects

⸻

CAMPFIRE SCALING

The fire may visually improve as the player progresses.

Examples:

larger flame

more decorative stones

better surroundings

additional lanterns

The fire should subtly communicate progression.

⸻

FOX COMPANION POSITION

The fox remains near the campfire.

The fox should appear naturally integrated into the environment.

The fox should never float.

The fox should never overlap UI.

The fox should feel physically present.

⸻

FOX BEHAVIOR

When idle:

sit

stretch

sleep

look around

watch fire

The fox should feel alive.

Not animated for the sake of animation.

⸻

QUEST BOARD

The Quest Board is a permanent structure.

It exists physically within the camp.

The board is not a floating UI card.

The player interacts with the board.

⸻

QUEST BOARD CONTENT

Daily Quests

Weekly Quests

Special Events

Limited Activities

⸻

QUEST BOARD INTERACTION

Tap Board

Board opens

Quest details appear

Board closes

Return to Camp

The player never leaves the camp context.

⸻

DAILY QUESTS

Daily Quests encourage consistent learning.

Daily Quests should feel achievable.

The player should rarely fail all daily quests.

⸻

DAILY QUEST PRESENTATION

Maximum visible quests:

3

The interface should remain clean.

No long scrolling lists.

⸻

QUEST REWARDS

Quest rewards should feel meaningful.

Examples:

XP

Cosmetics

Companion Items

Lantern Decorations

Titles

Special Currency

⸻

STREAK SHRINE

A dedicated shrine exists within the Camp.

Purpose:

Represent consistency.

Represent dedication.

Represent habit building.

⸻

STREAK VISUALIZATION

The shrine becomes more impressive over time.

Examples:

additional lanterns

larger decorations

extra visual effects

better architecture

The shrine should visibly reward commitment.

⸻

REWARD CHEST

The Camp contains a reward collection point.

Physical object.

Never floating UI.

Never a generic inbox.

⸻

REWARD STATES

Closed

Available

Opening

Opened

Collected

Each state should be visually distinct.

⸻

ACHIEVEMENT DISPLAY

Major achievements should appear as physical trophies.

Examples:

plaques

banners

ornaments

shrine additions

statues

Achievements should feel integrated into the world.

⸻

CAMP CUSTOMIZATION

Players may unlock camp upgrades.

Upgrades never break visual consistency.

Every customization must fit the world.

⸻

ALLOWED CUSTOMIZATIONS

Lantern Skins

Tent Variations

Camp Decorations

Companion Cosmetics

Banner Designs

Trail Decorations

⸻

FORBIDDEN CUSTOMIZATIONS

Modern Furniture

Neon Objects

Sci-Fi Elements

Corporate Objects

Random Novelty Items

Anything that breaks immersion

⸻

MEMORY BOOK

The Camp contains access to the Memory Book.

Purpose:

Review milestones.

Review journey history.

Celebrate achievements.

The Memory Book should feel personal.

Not statistical.

⸻

EVENT AREA

Events appear as temporary structures.

Examples:

Festival Stand

Special Shrine

Seasonal Decorations

Temporary Merchant

Event content should never replace permanent camp structures.

⸻

WEATHER SYSTEM

Weather affects Camp visuals.

Weather should enhance atmosphere.

Never reduce usability.

⸻

RAIN

Lantern reflections

Soft rain particles

Fox seeks shelter

Campfire protected

⸻

SNOW

Snow accumulation

Soft ambient lighting

Winter atmosphere

⸻

CLEAR NIGHT

Default state.

Most common.

Warmest presentation.

⸻

FESTIVAL STATE

Special decorations

Additional lanterns

Seasonal assets

Unique ambient effects

⸻

CAMP AUDIO

Audio should reinforce comfort.

Examples:

fire crackling

wind

birds

soft bells

distant water

Audio should never feel repetitive.

⸻

PLAYER RETURN EXPERIENCE

When returning from lessons:

the player should feel rewarded.

The camp should acknowledge progress.

Examples:

fox reaction

new reward

updated quest progress

visible XP gain

The Camp should celebrate effort.

⸻

EMPTY CAMP STATE

A new player should still find the Camp interesting.

The Camp should never feel empty.

Base assets must provide atmosphere even before progression.

⸻

ADVANCED PLAYER CAMP

Veteran players should visibly own a richer camp.

The Camp should become a reflection of their journey.

A player with 1000 completed lessons should have a noticeably more prestigious camp than a new player.

⸻

IMMERSION RULES

The Camp must always feel like a real place.

Every interaction should originate from a physical object.

Avoid floating menus whenever possible.

Prefer interacting with world objects.

The Camp is a location.

Not a screen.

⸻

FORBIDDEN DESIGNS

Do not use:

dashboard layouts

large statistics grids

achievement walls made of cards

notification centers

mailbox interfaces

productivity widgets

generic game home screens

The Camp should feel alive.

Not organized.

Not efficient.

Alive.
