NOBORU UI SPECIFICATION

DOCUMENT 13

ASSET PLACEMENT & USAGE SPECIFICATION

Version 1.0

⸻

PURPOSE

This document defines how approved assets are used throughout Noboru.

The project already contains approved artwork.

This document does not define asset creation.

This document defines:

* where assets may be used
* where assets may not be used
* visual ownership
* asset hierarchy
* asset frequency
* asset placement rules
* asset progression rules

This document exists to eliminate arbitrary asset usage.

No asset should appear because it looks good.

Every asset should appear because it belongs there.

⸻

CORE RULE

Assets are world building tools.

Assets are not decorations.

Assets communicate:

* progression
* location
* atmosphere
* history
* discovery

Every asset must support one of these purposes.

⸻

ASSET OWNERSHIP RULE

Every asset belongs to a system.

No asset is universal.

Every asset must have an owner.

Examples:

Trail Lantern → Journey System

Campfire → Camp System

Quest Board → Camp System

Fox Animations → Companion System

Merchant Assets → Shop System

Shrine Assets → Progression System

ASSET REUSE RULE

Asset reuse is encouraged.

Random asset swapping is forbidden.

Consistency creates identity.

Identity creates immersion.

⸻

IMPLEMENTATION TEST

Before placing any asset ask:

Why does this asset exist here?

Who owns this asset?

What system uses this asset?

What purpose does this asset serve?

Would the world lose meaning if this asset disappeared?

If no clear answer exists:

Do not place the asset.

⸻

FINAL RULE

Assets are not decoration.

Assets are storytelling.

Every mountain.

Every lantern.

Every shrine.

Every fox animation.

Every tree.

Every particle.

Must reinforce the feeling that the player is traveling through a living world.
